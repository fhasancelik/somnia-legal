# Somnia — legal pages

Public, statically hosted privacy policy and terms of use for the
**Somnia: Lucid Dream Journal** iOS app.

These live here rather than on the API for one reason: the API runs on a free
tier that sleeps when idle, and a privacy policy URL that returns a cold-start
timeout during App Review is a rejection. GitHub Pages is always up and serves
from a CDN.

- [Privacy Policy](https://fhasancelik.github.io/somnia-legal/privacy.html)
- [Terms of Use](https://fhasancelik.github.io/somnia-legal/terms.html)

Both documents are bilingual (Turkish and English) in a single page, so one URL
works for every storefront the app ships to.
